# Incident Copilot Mock Starter

This is a deliberately incomplete starter repository for a 2-hour Fireworks AI APM-style mock take-home.

## Before you begin

1. Do **not** open `INTERVIEWER_NOTES_AFTER_MOCK.md`.
2. Read `CANDIDATE_PROMPT.md`.
3. Create a Fireworks API key and choose a serverless text model available to your account.
4. Put credentials in `.env.local`:
   - `FIREWORKS_API_KEY`
   - `FIREWORKS_MODEL`
5. Run:

```bash
npm install
npm run dev
```

6. Confirm the starter page opens.
7. Start your 2-hour timer.
8. Stop when the timer ends.
9. Only then open `INTERVIEWER_NOTES_AFTER_MOCK.md`.

The incident data is fictional and created solely for interview practice.
